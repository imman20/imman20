## Pendidikan dan Skripsi

**S1 Statistika, Universitas Airlangga** (lulus 2024)

Skripsi: *Perbandingan Model Autoregressive Integrated Moving Average (ARIMA) dan Support Vector Regression (SVR) untuk Prediksi Nilai Tukar Rupiah terhadap Dolar AS*. Menggunakan 105 data mingguan kurs IDR/USD (Oktober 2021 sampai Oktober 2023), penelitian ini membangun model ARIMA (0,2,1) setelah transformasi Box-Cox dan differencing dua kali, lalu membandingkannya dengan SVR kernel RBF yang di-tuning lewat grid search. SVR kernel RBF menghasilkan MAPE 0,54% dibanding 2,49% pada ARIMA. Implementasi ulang dalam Python beserta pengembangan lanjutannya tersedia di repo [forecast-kurs-rupiah-arima-svr](https://github.com/imman20/forecast-kurs-rupiah-arima-svr).
